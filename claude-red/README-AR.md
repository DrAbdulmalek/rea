## 💡 الفكرة باختصار

`claude-red` مكتبة منتقاة بعناية من ملفات `SKILL.md` مهيكلة، تُحوِّل Claude إلى **مشغّل فريق أحمر (Red Team) واعٍ للسياق**. كل مهارة تتصرف كأخصائي متمرس في نطاق هجومي محدد: تعرف **التقنيات**، و**الأدوات**، والحالات **الحدّية (Edge Cases)**، ومسارات **التصعيد** — من حقن SQL إلى تطوير الاستغلالات، ومن تجاوز EDR إلى إساءة استخدام ADCS.

المهارات تُحمَّل **عند الطلب** بناءً على محفزات المحادثة؛ فلا تدفع ثمن سياق (Context) لمهارات لا تستخدمها. بدلًا من أن يخمّن الوكيل الأوامر، توجّهه هذه المكتبة إلى **منهجية هجومية منهجية وقابلة للتكرار** نفسها التي يتبعها المحترفون أثناء الاختبارات المصرَّح بها.

> ⚠️ **استخدام مسؤول:** هذه المكتبة مخصصة حصريًا للاختبارات **المصرَّح بها**: عمليات الفرق الحمراء المتعاقد عليها، فرز ثغرات Bug Bounty ضمن نطاق البرنامج، البحث الأمني، التحضير لـ CTF، وتدريب المشغّلين. أي استخدام غير مصرَّح به ضد أنظمة لا تملك إذنًا صريحًا لها غير قانوني وغير مقصود من هذه المكتبة.

## 🚀 التثبيت والاستخدام

### مع نظام مهارات Claude (الموصى به)

انسخ هذا المجلد (أو المستودع الأصلي) إلى مجلد مهارات Claude:

```bash
# من نسخة rea المحلية لديك:
cp -r rea/claude-red ~/.claude/skills/claude-red

# أو من المصدر الأصلي مباشرة:
git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red
```

يحمِّل Claude المهارة المطابقة تلقائيًا وفق سياق المحادثة (مثال: ذكر «حقن SQL» يُحمِّل `offensive-sqli`).

### مع Claude Code

```bash
cat claude-red/Skills/web/offensive-sqli/SKILL.md | claude --system-file -

cat claude-red/Skills/infrastructure/**/SKILL.md | claude --system-file -
```

### مع Claude.ai يدويًا

الصق محتوى ملف `SKILL.md` المطلوب في System Prompt الخاص بمشروع (Project) أو أضِفه إلى بداية المحادثة.

### سكربت التثبيت التفاعلي

```bash
./claude-red/install.sh                           # تفاعلي
./claude-red/install.sh --target ~/.claude/skills # هدف صريح
./claude-red/install.sh --category web            # فئة واحدة فقط
```

## 🗺️ خارطة الطريق

تتوسع المكتبة عبر مراحل متعددة — اكتملت مراحل اللاسلكي (+12) والفئات الجديدة (+20) وإعادة الكتابة العميقة، والمخطط إضافة مهارات AD الداخلية والهوية السحابية وIoT والويب الأساسي والمتقدم حتى ~130 مهارة. التفاصيل في [CHANGELOG.md](CHANGELOG.md).

## 🤝 لماذا ضُمِّنت في rea؟

يضم مستودع rea مكتبات منهجيات أمنية ووكالات ذكاء اصطناعي متنوعة؛ إضافة `claude-red` تكمل طرف «الهجوم المصرَّح به» بجوار طرف `reverse-skill` (المنهجية التحليلية)، فيصبح لدى الوكيل مرجع موحّد للمنهجيتين: كيف يفكّك هدفًا، وكيف يختبر نطاقًا هجوميًا بطريقة منهجية موثّقة.
